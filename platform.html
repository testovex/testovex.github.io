API Testing

Paste a curl command, import a Postman collection, or upload an OpenAPI / Swagger file (3.x or 2.0, JSON or YAML). Browser Recorder
From first click to passing test — in minutes.

The Testovex recorder isn't just a click capturer. It's the foundation of the Smart Locator Engine — capturing 9 locator strategies per element as you record, so tests are stable before you even run them for the first time.

1
Install the extension & start recording

Open your app in Chrome, click Record in the Testovex extension. Every interaction is captured — clicks, form fills, assertions, navigation.

⏱ Under 60 seconds to start
2
Semantic capture — not just "click"

check, uncheck, doubleClick, rightClick are recorded as distinct step types. iFrame interactions, alert handling, canvas actions — all captured as readable keyword steps.

3
9 locator strategies saved per element

While you click, the engine silently captures Test ID, ARIA Role, Label, Placeholder, CSS, XPath and more. The most stable strategy is pre-selected. Fallbacks are ready.

✓ Stable from the very first recording
4
Review, enrich & run

Edit steps in the visual builder, add variables, assertions, and control flow. Then run — from the platform or straight from your terminal with the CLI.

⚡ Authoring to execution in minutes

When a test fails in CI at 2 am, you shouldn't need to reproduce it locally. Testovex automatically records every run — video, screenshots, and a full Playwright trace — so the answer is waiting the moment you open the result.

Automatic video recordingFull browser session captured on every run — even headless. Watch exactly what the browser did, frame by frame.

Every entity versioned. Every sprint committed. Every mistake undoable.

Testovex snapshots every test case, component, suite, and object before each save — automatically. See exactly what changed, who changed it, and when. Restore any entity individually or commit your entire project state as a named Milestone.

Per-entity history — all 4 typesTest cases, components, suites, and objects each carry their own 50-version history with before → after diffs.
Project MilestonesName and commit the current state of your entire project. Restore everything in one click if the next sprint breaks something.
Before → after change detailHistory doesn't just say "name changed" — it shows the old value crossed out and the new value highlighted, for every field.

CLI Support
Your pipeline. Your scripts.
Testovex fits right in.

Don't wait for a native CI/CD connector. Hook Testovex into any pipeline, script, or cron job you already have — today. GitHub Actions, Jenkins, GitLab CI, Bitbucket Pipelines — if it can run a shell command, it can run Testovex.

testovex loginAuthenticate, supports multi-org accounts with interactive picker or --org flag for CI
testovex runTrigger any suite with --wait to block until complete. Exit code 1 on failure for CI gating.
testovex rerunRepeat a run with the same test data to reproduce a failure
testovex resultsDetailed pass/fail output for any run ID, with data-driven rows grouped per test case
testovex whoami / logoutSession management for shared CI environments
